## Overview

`octopus` is a collection of small libraries that make working with files and directories simple, fast, and reliable.

It contains two independent packages:

- [dirreader](https://github.com/gromey/octopus/blob/main/dirreader/README.md) - Concurrent directory reader with optional file hashing
- [zipper](https://github.com/gromey/octopus/blob/main/zipper/README.md) - Tools for creating and extracting ZIP archives

## 📦 Installation

```bash
  go get github.com/gromey/octopus@latest
```
